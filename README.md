# NEO-SYSTEM

Sistema de gestão para empresas de genba (manutenção e construção terceirizada) com equipes estrangeiras no Japão: escalação, confirmação diária pelo celular, 勤怠表, 請求書, folha de pagamento, financeiro e documentos — em vários idiomas.

**Situação:** fundação (M0). Primeira cliente: Sugita Kogyo (株式会社杉田工業).
